# ระบบรับสมัครเรียนออนไลน์ (รอบโควตา / กรณีพิเศษ ๒๕๗๐)
## วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ (Thaluang Cement Thai Anusorn Technical College)

ระบบเว็บแอปพลิเคชันรับสมัครนักเรียน นักศึกษาใหม่ แบบครบวงจร พัฒนาขึ้นเพื่อทดแทนระบบใบสมัครกระดาษและ Google Form + AutoCrat เดิม รองรับการใช้งานผ่านสมาร์ตโฟนและแท็บเล็ต 100% (Mobile-first, Responsive)

---

## 🌟 คุณสมบัติเด่นของระบบ

### 1. ส่วนสำหรับผู้สมัคร (Applicant Portal)
- **ฟอร์มรับสมัครแบบ Step-by-Step (4 ขั้นตอน)** พร้อม Progress Bar ที่เข้าใจง่าย
- **ระบบบันทึกร่างอัตโนมัติ (Auto-Save)** ข้อมูลไม่สูญหายเมื่อเผลอปิดหรือสลับหน้าจอมือถือ
- **ข้อมูลครบตรงตามใบสมัครจริงของวิทยาลัย 100%**:
  - เลือกระดับ: ปวช. (เลือกได้ 2 อันดับไม่ซ้ำกัน), ปวส. สายตรง, ปวส. ม.6/ต่างสาขา
  - อัปโหลดรูปถ่ายหน้าตรงขนาด 1 นิ้ว
  - ข้อมูลส่วนตัวและครอบครัว (ข้อ ๑, ๒, ๓)
  - ที่อยู่พร้อม **ระบบค้นหาตำบล/อำเภอ/จังหวัด/รหัสไปรษณีย์อัตโนมัติ (Autocomplete)** (ข้อ ๔)
  - ประวัติสถานศึกษาเดิม และผลการเรียนเฉลี่ยสะสม 5 ภาคเรียน (GPAX 0.00 - 4.00) (ข้อ ๕)
  - เลือกสาขาวิชาที่เปิดรับตามระดับ (ข้อ ๖)
  - การยินยอมข้อมูลส่วนบุคคลตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)
- **ระบบตรวจสอบความถูกต้อง (Validation)**:
  - ตรวจสอบความถูกต้องของเลขประจำตัวประชาชน 13 หลักด้วยอัลกอริทึม Checksum (Mod 11) และป้องกันการสมัครซ้ำ
  - ตรวจสอบรูปแบบเบอร์โทรศัพท์ 10 หลักขึ้นต้นด้วย 0
  - ตรวจสอบเกรดเฉลี่ยสะสม GPAX ระหว่าง 0.00 ถึง 4.00
- **ระบบอัปโหลดเอกสารหลักฐาน**:
  - เอกสารแสดงผลการเรียน 5 ภาคเรียน (ปพ.๑), สำเนาบัตรประชาชน/ทะเบียนบ้าน, เกียรติบัตร
  - ป้องกันสแปมด้วยระบบ Honeypot และ Rate limit
- **หน้าตรวจสอบสถานะการสมัคร**:
  - ค้นหาด้วยเลขบัตรประชาชน 13 หลัก + วันเดือนปีเกิด
  - แสดงสถานะ: *รอตรวจสอบ*, *เอกสารไม่สมบูรณ์*, *ผ่านการคัดเลือก*, *ไม่ผ่าน*, *มอบตัวแล้ว*
  - กรณีเอกสารไม่ครบ ผู้สมัครสามารถอัปโหลดเอกสารแก้ไขส่งให้เจ้าหน้าที่ตรวจใหม่ได้ทันที
- **การพิมพ์และดาวน์โหลดเอกสาร PDF (ขนาด A4)**:
  - **ใบสมัครเข้ารับคัดเลือกโควตา A4**: หัวเรื่อง ตราวิทยาลัย ตรา สอศ. ข้อความตรงตามใบสมัครกระดาษของวิทยาลัย 100% มี QR Code สำหรับเจ้าหน้าที่สแกนเปิดดูข้อมูล
  - **ตัวเลือกสลับเลขไทย/เลขอารบิก** (เช่น ๑, ๒, ๓)
  - **ใบรายงานตัวและมอบตัวนักศึกษา A4**: ดาวน์โหลดได้ทันทีเมื่อผ่านการคัดเลือก

### 2. ส่วนสำหรับเจ้าหน้าที่และผู้บริหาร (Admin Portal)
- **ระบบรักษาความปลอดภัยและการยืนยันตัวตน (RBAC)**:
  - แบ่งบทบาท 3 ระดับ: `Super Admin`, `เจ้าหน้าที่งานทะเบียน (Registrar)`, `ผู้บริหารดูผลอย่างเดียว (Viewer)`
- **ตารางจัดการรายชื่อผู้สมัคร (Applicant Management)**:
  - ค้นหาละเอียดตามชื่อ เลขใบสมัคร เลขบัตรประชาชน โรงเรียนเดิม
  - ตัวกรองแยกตาม: ปีการศึกษา, ระดับชั้น (ปวช./ปวส.), สาขาวิชา, สถานะ, จังหวัด
  - **การจัดการหลายรายการพร้อมกัน (Bulk Action)**: อนุมัติผ่านการคัดเลือก หรือแจ้งขอเอกสารเพิ่มพร้อมกันหลายคน
- **หน้ารายละเอียดผู้สมัครเชิงลึก**:
  - ดูข้อมูลครบถ้วนทุกข้อ ดูเอกสารแนบและรูปถ่าย
  - แก้ไขข้อมูล เปลี่ยนสถานะ ระบุเหตุผล และบันทึกประวัติการเปลี่ยนแปลง (**Audit Log**) ทุกครั้ง
- **ระบบมอบตัวและออกรหัสนักเรียน/นักศึกษาอัตโนมัติ**:
  - บันทึกชื่อผู้ปกครอง พยาน วันที่มอบตัว
  - ออกรหัสนักศึกษาใหม่อัตโนมัติตามรูปแบบที่ตั้งค่าไว้ (เช่น ปวช. `70201xxxxx`, ปวส. `70301xxxxx`)
- **แดชบอร์ดสถิติและกราฟวิเคราะห์ (Analytics with Recharts)**:
  - ยอดผู้สมัครเปรียบเทียบกับโควตารับในแต่ละสาขาวิชา
  - สัดส่วนผู้สมัครตามระดับการศึกษา
  - 5 อันดับโรงเรียนเดิม และจังหวัดที่มีผู้สมัครมากที่สุด
  - สัดส่วนช่องทางที่รู้จักวิทยาลัย
- **การส่งออกข้อมูล (Export)**:
  - ไฟล์ Excel (.xlsx) จัดรูปแบบคอลัมน์พร้อมนำเข้าระบบทะเบียน
  - ไฟล์ CSV เข้ารหัส **UTF-8 with BOM** ทำให้เปิดในโปรแกรม Microsoft Excel บน Windows ได้ภาษาไทยไม่เป็นภาษาต่างดาว
- **การตั้งค่าระบบ (Settings)**:
  - สวิตช์เปิด-ปิดการรับสมัครและข้อความประกาศ
  - กำหนดขนาดไฟล์สูงสุด
  - รูปแบบการออกรหัสนักศึกษา
  - สวิตช์เปิด-ปิดการแจ้งเตือนทาง LINE Messaging API / Email Notification

## 🛠 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Server Actions, API Routes)
- **Language**: TypeScript
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Form & Validation**: [React Hook Form](https://react-hook-form.com/) + [Zod](https://zod.dev/)
- **Charts & Data Visualization**: [Recharts](https://recharts.org/)
- **Spreadsheet Engine**: [SheetJS (xlsx)](https://docs.sheetjs.com/)
- **QR Code Generator**: [qrcode](https://www.npmjs.com/package/qrcode)
- **Database & Storage**: Dual-mode Architecture:
  - รองรับ [Supabase](https://supabase.com/) (PostgreSQL + Storage + RLS)
  - มี Local File DB Adapter ในตัว ทำให้ทดสอบได้ทันทีไม่ต้องติดตั้ง Database ภายนอกก่อน

## 🚀 วิธีการติดตั้งและการเริ่มใช้งาน (Setup Guide)

### 1. ความต้องการของระบบ (Prerequisites)
- [Node.js](https://nodejs.org/) เวอร์ชัน 18.18 หรือสูงกว่า (แนะนำ Node.js 20 หรือ 22)
- ระบบปฏิบัติการ: Windows, macOS หรือ Linux

### 2. การติดตั้ง Dependencies
เปิด Terminal หรือ Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:

```bash
npm install
```

*(สำหรับระบบ Windows PowerShell หากติด Execution Policy สามารถใช้ `npm.cmd install`)*

### 3. การตั้งค่าตัวแปรสภาพแวดล้อม (Environment Variables)
คัดลอกไฟล์ `.env.example` ไปเป็น `.env.local`:

```bash
cp .env.example .env.local
```

รายละเอียดตัวแปรใน `.env.local`:

```env
# โหมดฐานข้อมูล: "local" (ทำงานได้ทันที) หรือ "supabase"
DATA_PROVIDER=local

# การเชื่อมต่อ Supabase (หากต้องการเชื่อมต่อ Supabase Cloud)
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

# รหัสผ่านสำหรับ Admin เริ่มต้น
ADMIN_DEFAULT_PASSWORD=admin1234

# โมดูลแจ้งเตือน LINE (ไม่บังคับ)
LINE_NOTIFY_TOKEN=
LINE_CHANNEL_ACCESS_TOKEN=

# โมดูลแจ้งเตือนอีเมล (ไม่บังคับ)
RESEND_API_KEY=
FROM_EMAIL=admission@thaluang.ac.th
```

### 4. รันระบบเพื่อพัฒนา (Development Mode)

```bash
npm run dev
```

เปิดเว็บเบราว์เซอร์ไปที่: **`http://localhost:3000`**

## 🗄️ การติดตั้ง Database บน Supabase (Production Deployment)

หากต้องการนำระบบขึ้นใช้งานจริงด้วยฐานข้อมูล Supabase:
1. สร้างโปรเจกต์ใหม่ที่ [Supabase](https://supabase.com/)
2. ไปที่เมนู **SQL Editor** ใน Supabase Dashboard
3. คัดลอกสคริปต์ทั้งหมดจากไฟล์ `supabase/schema.sql` ในโปรเจกต์นี้ ไปวางแล้วกด **Run**
4. ไปที่เมนู **Storage** ใน Supabase สร้าง Bucket ชื่อ `applicant-documents` ตั้งเป็น Private
5. คัดลอก `Project URL` และ `anon key` จากเมนู **Settings > API** มาใส่ใน `.env.local`
6. เปลี่ยนค่า `DATA_PROVIDER=supabase` ใน `.env.local`

## 🌐 การนำขึ้นระบบจริง (Deployment on Vercel)

1. นำโค้ดขึ้น GitHub Repository
2. เข้าสู่ [Vercel](https://vercel.com/) และเลือก **Import Project** จาก Repository ดังกล่าว
3. ในหน้า **Environment Variables** บน Vercel ให้กรอกค่าตัวแปรจากไฟล์ `.env.local`
4. กด **Deploy** เว็บไซต์จะพร้อมใช้งานทันทีภายใน 2-3 นาที
